# JFSDSDPProject

> CareerStream, a Spring Boot campus recruitment and job-application platform.

## Overview

The project provides separate workflows for students, recruiters, and administrators, including job discovery, applications, and recruiter-side management. It is the broader academic project associated with the recruiter service module.

## What’s in this repo

- Student profiles, job search, applications, and application-status tracking
- Recruiter job and applicant management
- Administrative account and platform oversight

## Stack

Java 17, Spring Boot, Maven, MySQL, JSP, HTML, CSS, and JavaScript.

## Getting started

1. Install JDK 17 and configure a MySQL database for the application.
2. Use the Maven wrapper to build the project: `./mvnw clean package` (Windows: `mvnw.cmd clean package`).
3. Follow the application configuration in the source before running or deploying.

## Notes

This is an academic group project. The README documents project features; review the current configuration and database schema before using it in another environment.
